  1. Your extensions

Or install from a terminal, without the security prompt

macOS, in Terminal (run it again to update):

curl -fsSL {{site}}/install.sh | sh

Windows, in PowerShell:

irm {{site}}/install.ps1 | iex

Each checks the download against the release's SHA256SUMS.txt before it installs anything. Install notes.
